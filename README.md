# Image Uploader — PHP + MySQL

مشروع عربي لرفع الصور بواجهة RTL قابلة للتطوير باستخدام PHP وMySQL.

**الحد الأقصى للصورة الواحدة: 30 MiB** (31,457,280 بايت). الأنواع المسموحة افتراضيًا: JPEG وPNG وWebP وGIF وBMP.

## المزايا
- اختيار عدة صور والسحب والإفلات وعرض تقدم الإرسال.
- التحقق على الخادم من الحجم وMIME ومحتوى الصورة.
- أسماء تخزين عشوائية وتخزين خارج مجلد public.
- حفظ بيانات الصور الوصفية في MySQL باستخدام PDO.
- معرض صور، عرض وتنزيل، وحذف عبر POST مع رمز CSRF.
- واجهة عربية RTL متجاوبة وتعليقات وتوثيق.

## المتطلبات
PHP 8.1+ مع إضافتي pdo_mysql وfileinfo، وMySQL أو MariaDB، وخادم ويب يجعل public/ هو Document Root.

## التثبيت
1. أنشئ قاعدة بيانات ومستخدمًا بصلاحيات محدودة.
2. نفّذ database/schema.sql.
3. انسخ app/Config/config.example.php إلى app/Config/config.php وعدّل بيانات الاتصال.
4. اجعل Document Root يشير إلى public/ فقط.
5. امنح PHP صلاحية الكتابة إلى storage/uploads/ وstorage/logs/.
6. راجع docs/INSTALLATION.md وdocs/CONFIGURATION.md وdocs/SECURITY.md.

## الهيكل
- app/Config: إعدادات البيئة؛ config.php لا يرفع إلى Git.
- app/Database: اتصال PDO.
- app/Helpers: التهيئة والأمان والتنسيق.
- app/Repositories: استعلامات MySQL.
- app/Services: التحقق من الصور وتخزينها.
- public: صفحات الويب والأصول.
- storage: الصور والسجلات خارج جذر الويب.
- database: مخطط قاعدة البيانات.
- docs: أدلة التثبيت والتهيئة والأمان.

## ملاحظات
- حد 30 MiB يتطلب توافق إعدادات PHP وخادم الويب والاستضافة.
- لا يتضمن الإصدار حسابات مستخدمين أو صلاحيات إدارية؛ لا تنشر واجهة الحذف للعامة قبل إضافة المصادقة.
- لم يُدّعَ اختبار المشروع على استضافتك الفعلية؛ اختبره قبل النشر.

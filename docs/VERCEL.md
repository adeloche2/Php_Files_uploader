# نشر المشروع على Vercel باستخدام PHP

## كيف يعمل
- `vercel.json` يحدد Community PHP Runtime `vercel-php@0.9.0` بدل Vite.
- `api/index.php` مدخل PHP يوجه الطلبات إلى الصفحة الرئيسية وواجهات الرفع والعرض والتنزيل.
- الملفات الثابتة مثل CSS وJavaScript تُخدم من filesystem؛ المسارات الديناميكية تُوجّه إلى PHP.
- `composer.json` يطلب AWS SDK for PHP لتوقيع روابط S3-compatible.
- لا تمر بيانات الصورة عبر PHP/Vercel: يحصل المتصفح على رابط PUT موقّع ويرفع مباشرة إلى مخزن الكائنات، ثم يسجل التطبيق metadata في MySQL.
- لا تُخزن الصور على قرص Vercel؛ قاعدة البيانات تحفظ metadata ومفتاح الكائن فقط.

## إعداد Vercel
1. افتح إعدادات المشروع في Vercel.
2. غيّر Framework Preset إلى **Other**، واحذف أي Build Command قديم مثل `vite build`. راجع إعدادات لوحة Vercel بعد إضافة `vercel.json`.
3. تأكد أن Root Directory يشير إلى جذر المستودع.
4. أضف المتغيرات من `.env.example` في Project Settings → Environment Variables. لا ترفع أسرارًا إلى Git.
5. أعد النشر بعد إضافة المتغيرات.

## MySQL
استخدم MySQL مُدارًا يمكن الوصول إليه عبر الإنترنت. أنشئ قاعدة بيانات ومستخدمًا بصلاحيات محدودة، ثم نفذ `database/schema.sql`. ضع بيانات الاتصال في `DB_HOST` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD`. اتبع إعداد TLS الخاص بمزود قاعدة البيانات عند الحاجة.

## التخزين الدائم
يستخدم المشروع واجهة S3-compatible مثل Cloudflare R2 أو AWS S3:
- أنشئ bucket خاصًا ومفتاح وصول بأقل صلاحيات لازمة.
- اضبط `S3_ENDPOINT` و`S3_REGION` و`S3_BUCKET` و`S3_ACCESS_KEY_ID` و`S3_SECRET_ACCESS_KEY`.
- في Cloudflare R2، يكون endpoint عادةً `https://<account-id>.r2.cloudflarestorage.com` والمنطقة `auto`.
- اضبط CORS على bucket للسماح بأصل موقعك وطريقة `PUT` وترويسة `Content-Type`.
- يستخدم التطبيق روابط GET موقعة قصيرة الأجل للعرض والتنزيل؛ لا يلزم جعل bucket عامًا.
- رابط الرفع صالح لعشر دقائق، ويجب إكمال الرفع عبر `/api/upload-complete`.

## حد 30 MiB
الرفع المباشر إلى object storage يتجنب إرسال ملف 30 MiB داخل طلب PHP إلى Vercel. التطبيق يرفض الملفات الأكبر من `30 * 1024 * 1024` بايت.

## الأمان والحدود الحالية
- ضع سرًا عشوائيًا طويلًا في `APP_KEY` ولا تستخدم القيمة النموذجية.
- فحص الإكمال يتحقق من الحجم ونوع المحتوى المعلن من التخزين؛ هذا ليس تحليلًا كاملًا لبايتات الصورة. قبل استقبال ملفات عامة غير موثوقة، أضف تحققًا وإعادة ترميز عبر عامل معالجة مستقل.
- لا توجد حسابات مستخدمين أو ملكية للصور؛ حذف الصور متاح لأي زائر يصل إلى الصفحة. لا تنشر واجهة الحذف للعامة قبل إضافة المصادقة والتفويض أو تعطيل الحذف.
- نجاح البناء لا يثبت صحة متغيرات البيئة أو الاتصال بقاعدة البيانات أو CORS؛ اختبر الرفع والعرض والتنزيل والحذف بعد النشر.
- Community PHP Runtime ليس runtime رسميًا مدمجًا من Vercel؛ راجع مستودعه عند التحديث.

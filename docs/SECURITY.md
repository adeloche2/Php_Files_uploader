# الأمان وحدود الإصدار الحالي

- يستخدم التطبيق PDO واستعلامات محضرة، وأسماء مفاتيح تخزين عشوائية، وروابط رفع وتنزيل مؤقتة، ورمز CSRF موقّعًا stateless.
- بيانات الاعتماد يجب أن تبقى في إعدادات البيئة، لا في Git.
- روابط الرفع صالحة لعشر دقائق، ويتحقق مسار الإكمال من حجم الملف ونوع المحتوى المبلغ عنه من object storage.
- فحص MIME من بيانات التخزين لا يثبت أن البايتات صورة سليمة؛ أضف فحصًا حقيقيًا وإعادة ترميز للصور قبل استقبال ملفات عامة غير موثوقة.
- لا توجد حسابات مستخدمين أو ملكية للصور. يستطيع الزوار رؤية الصور. الحذف معطّل افتراضيًا؛ لا تضبط `ENABLE_PUBLIC_DELETE=true` قبل إضافة مصادقة وتفويض إداري.
- أضف تحديد معدل الرفع وحدًا إجماليًا للتخزين ومراقبة للتكلفة.
- احتفظ بالـ bucket خاصًا واستخدم روابط GET موقعة قصيرة الأجل.
- لا يعتبر نجاح البناء اختبارًا لاتصال MySQL أو بيانات S3 أو إعداد CORS. اختبر كل العمليات بعد النشر.

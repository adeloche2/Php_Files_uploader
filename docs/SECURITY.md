# الأمان وحدود النسخة الأولى

تتحقق الخدمة من الحجم وMIME باستخدام Fileinfo وإمكانية تحليل الصورة، وتولد أسماء تخزين عشوائية، وتستخدم PDO واستعلامات محضرة، وتهرب النصوص في HTML. التخزين خارج public/، والحذف عبر POST مع CSRF.

**لا تنشر الموقع عامًا بصورته الحالية دون مصادقة وصلاحيات إدارية.** لا يوجد نظام حسابات أو ملكية للصور، لذا واجهة الحذف تحتاج حماية إضافية قبل الاستخدام العام. أضف تحديد معدل الرفع وحدًا إجماليًا للتخزين، واستخدم HTTPS، وحدث PHP/MySQL، وراجع سجلات الأخطاء. فحص MIME والأبعاد لا يضمن خلو كل صورة من المخاطر؛ يمكن إضافة فك ترميز وإعادة ترميز للصور عبر مكتبة محدثة.

الملفات وقاعدة البيانات لا تشتركان في معاملة ذرية؛ عند فشل إدخال سجل بعد نقل الملف تحاول الصفحة حذف الملف، لكن يجب مراجعة الحالات الاستثنائية دوريًا.
